# Portfolio Monika Müller

Die Datei `index.html` ist eine eigenständige responsive Webseite. Lokal per Doppelklick öffnen.

## Vor Veröffentlichung

- Inhalte durch Monika prüfen und freigeben lassen.
- Im Konfigurationsblock `const config` am Ende der HTML-Datei die tatsächlichen GitHub-URLs für `github`, `railguard` und `bmi` ergänzen. Leere Angaben werden nicht angezeigt.
- Optional `praktikumszeitraum` und eine zur Veröffentlichung freigegebene `email` ergänzen.
- Datenschutz und mögliche Impressumspflicht prüfen; bei Bedarf eine rechtliche Hinweisseite anlegen und unter `legal` verlinken.
- Die Projektgrafiken sind Illustrationen. Eigene freigegebene Screenshots können sie später ersetzen. Das Bewerbungsfoto ist bewusst nicht enthalten.
- Projekt-Repositories auf vertrauliche Daten, Zugangsdaten (auch in der Historie) und Veröffentlichungsrechte prüfen.

## GitHub Pages

1. Öffentliches Repository mit dem Namen `BENUTZERNAME.github.io` erstellen.
2. `index.html` in das Hauptverzeichnis des Branches `main` hochladen.
3. Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Nach der Bereitstellung `https://BENUTZERNAME.github.io` öffnen und testen.

Die README kann ebenfalls hochgeladen werden, ist aber für die Webseite nicht erforderlich.
